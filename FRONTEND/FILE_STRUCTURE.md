## Key Files Explained

### `src/App.jsx` - Main Router
```jsx
// Imports all pages with lazy loading
const Home = lazy(() => import('./pages/Home'))
const Heritage = lazy(() => import('./pages/Heritage'))
// ... 9 pages total

// Routes with paths
<Route path="/" element={<Home/>} />
<Route path="/heritage" element={<Heritage/>} />
// ... all 9 pages routed
```

### `src/i18n.js` - Translations
```javascript
const resources = {
  en: { translation: { home: 'Home', ... } },
  hi: { translation: { home: 'मुख पृष्ठ', ... } }
}
```

```javascript
export const useStore = create(set => ({
  dark: false,
  setDark: (val) => { set({ dark: val }); localStorage.setItem(...) },
  loadPrefs: () => { /* restore from localStorage */ }
}))
```

## How to Add a New Feature

### Example: Add a Blog Page

1. **Create page file**
   ```
   src/pages/Blog.jsx
   ```

2. **Update routes in src/App.jsx**
   ```jsx
   const Blog = lazy(() => import('./pages/Blog'))
   <Route path="/blog" element={<Blog/>} />
   ```

3. **Add nav link in src/components/Navbar.jsx**
   ```jsx
   <NavLink to="/blog">Blog</NavLink>
   ```

4. **Add translation in src/i18n.js**
   ```javascript
   en: { translation: { blog: 'Blog' } },
   hi: { translation: { blog: 'ब्लॉग' } }
   ```

5. **Run dev server**
   ```bash
   npm run dev
   ```

## SEO Meta Tags

Located in `index.html` and set dynamically with React Helmet:

```html
<meta name="description" content="Explore Indian heritage..." />
<meta property="og:title" content="Heritage & Culture Portal" />
<meta property="og:image" content="/assets/og-image.jpg" />
<meta name="theme-color" content="#7A5C3A" />
```

Each page can override with:
```jsx
<Helmet>
  <title>Custom Title</title>
  <meta name="description" content="Page description" />
</Helmet>
```
